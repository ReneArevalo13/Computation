# Computation 🔢

A dedicated environment for practicing **numerical methods**, scientific computing, and algorithmic simulations. This directory serves as a sandbox for implementing mathematical models and continuous approximations.

## 📁 Repository Structure

*   📂 **`01_root_finding/`** — Methods for finding zeros of functions (e.g., Bisection, Newton-Raphson, Secant method).
*   📂 **`02_linear_algebra/`** — Systems of linear equations and matrix operations (e.g., Gauss elimination, LU decomposition, Jacobi/Gauss-Seidel iteration).
*   📂 **`03_interpolation_regression/`** — Curve fitting, polynomial interpolation, and least-squares approximations.
*   📂 **`04_calculus/`** — Numerical differentiation and integration (e.g., Trapezoidal rule, Simpson's rules, Gauss quadrature).
*   📂 **`05_differential_equations/`** — Solvers for ODEs and PDEs (e.g., Euler's method, Runge-Kutta methods).
*   📂 **`06_simulations/`** — Stochastic models, optimization problems, and Monte Carlo methods.

## 📝 General Practice Workflow

1.  **Formulate:** Define the mathematical problem and governing equations.
2.  **Discretize:** Convert continuous equations into discrete, machine-solvable forms.
3.  **Implement:** Code the algorithm from scratch (avoiding high-level library shortcuts when learning the core logic).
4.  **Verify & Visualize:** Test against known analytical solutions and plot the error/convergence rates.
